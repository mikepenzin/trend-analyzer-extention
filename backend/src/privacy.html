Privacy Policy

Last updated: March 18, 2026

Trend Analyzer ("the Extension") is a Chrome browser extension that uses AI to analyze the content of web pages you are actively viewing. This policy explains how data is handled.

1. What data is collected

When you explicitly trigger an analysis, the Extension reads the visible text content, page structure (DOM), and optionally a screenshot of the currently active browser tab. This content is sent to the Extension's backend server for processing.

2. How data is used

The page content is sent solely to generate an AI-powered analysis result that is displayed to you in the Extension's side panel. The data is:

  • Processed in real time and not stored or logged on the server
  • Not used for any purpose other than producing the analysis you requested
  • Not used to build profiles, track behaviour, or train AI models

3. Third-party AI providers

To generate the analysis, page content is forwarded to one or more third-party AI APIs (Google Gemini, Groq, or OpenAI) depending on the provider selected. Each provider's own privacy policy applies to data they receive:

  • Google Privacy Policy
  • Groq Privacy Policy
  • OpenAI Privacy Policy

4. Data sharing

We do not sell, trade, or transfer your data to any third parties beyond the AI providers listed above, which are necessary to operate the Extension.

5. Data retention

No user data is stored by the Extension's backend. All processing is ephemeral — data exists only for the duration of a single API request.

6. Local storage

The Extension may store user preferences (such as selected AI provider or license key) locally in Chrome's extension storage. This data never leaves your device.

7. Contact

If you have questions about this policy, please open an issue on the project's GitHub repository.
